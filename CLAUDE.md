# Сходка — контекст для Claude

Агент собирает новости и присылает в Telegram (**@le18_bot**) готовые
СПРАВКИ для редактора-человека: заголовок, суть в 2–3 предложения,
ссылки на источники и обязательно фото. Публикует пост сам заказчик —
агент не сочиняет пост в голосе канала, только готовит материал.

Полное описание пайплайна (сбор → группировка → проверка → черновик) —
в README.md. Он читается вместе с этим файлом, но местами **устарел**:
профиль и формат менялись позже устного решения заказчика. При расхождении
верь этому файлу и последним коммитам, а не README.

## Что изменилось и не описано в README

- **Профиль — молодёжная культура**, не культура вообще: хип-хоп, стритвир/
  кроссовки, показы и модные дома, НБА и футбол как культура, немного
  громкого кино. **Архитектура и «высокая» культура (музеи, театр, выставки)
  убраны — заказчик прямо отказался.** Не предлагать вернуть.
- **Модель — только Groq `openai/gpt-oss-120b`.** Gemini недоступен из России,
  ключ завести не вышло — не пытаться подключать его снова.
- **Формат — не готовый пост, а карточка-справка** (заголовок, суть ~350
  знаков, источники, фото). Фото обязательно: если своего в новости нет —
  Wikipedia REST API по герою новости, запасной вариант Openverse.
- Источников 15 (не 37), намеренно только крупные издания.

## Технические ограничения — не трогать не разобравшись

- **Groq: 8000 токенов/мин** — главное ограничение всего проекта. Отсюда
  пачки по 18 материалов, пауза 13с между вызовами, `MAX_PER_RUN=80`, в
  модель уходят только заголовки без описаний. Увеличишь пачку — 413.
- Строгий JSON-режим Groq ломается на длинных ответах (пустой ответ +
  `json_validate_failed`) — в `llm.ts` есть запасной путь через свободный
  режим, он должен остаться.
- `CATEGORY_LIMIT` / `SPORT_LIMIT` — без них одна лента (спорт, раньше
  архитектура) вытесняет из выдачи всё остальное.
- `quality.ts` ловит дописанную моделью рекламу и выдумки в конце текста
  списками/регэкспами — промтом это не лечится, не убирать эти проверки.
- Список источников в `sources.ts` настроен пробами и ошибками,
  `REJECTED_SOURCES` внизу файла — кого пробовали и почему не вышло.
  Не перепроверять без новой причины.

## Правила безопасности

- Репозиторий **публичный намеренно** (иначе только 2000 бесплатных минут
  GitHub Actions в месяц) — не делать приватным.
- `.env` с ключами (Groq, Neon, Telegram) — только у владельца локально и в
  GitHub Secrets. В репозитории его нет и быть не должно.
- На этой копии (бридж-бот) `.env` тоже нет — пайплайн здесь реально не
  запустить (нет доступа к Neon/Groq/Telegram), только читать и править код.
  Если нужна проверка вживую — сказать владельцу, он прогонит на своей
  машине или через `gh workflow run`.
- **Neon — общая боевая база.** К изменениям `prisma/schema.prisma` и
  миграциям относиться осторожно: если не уверен в последствиях для живых
  данных — сначала спросить владельца, потом делать.
- Не смягчать и не переписывать правила в `style.ts` и `quality.ts` без
  явной просьбы — они появились как реакция на конкретные баги модели,
  описанные выше и в README.
